VK01 Studio: custom software for the ANTICATER VK01 knob

Assign single, double, triple and long presses to media controls or Windows audio-output switching. Cycle between speakers, headphones and USB DACs with your desktop volume knob.

Download for Windows x64 GitHub & setup instructions

What can VK01 Studio do?

Custom click gestures

Configure single, double, triple and hold gestures for play/pause, next/previous track, mute or audio switching.

Audio device switching

Choose Windows playback outputs and cycle between headphones, speakers and USB DACs in your preferred order.

Timing calibration

Adjust click and hold thresholds, practice gestures and measure timing for your own input style.

USB and 2.4 GHz modes

Supports tested wired USB input and the supplied 2.4 GHz USB receiver, with different click mappings.

See the Windows app

How to set up ANTICATER VK01

  1. Download the current VK01 Studio release and unzip it to a permanent folder.
  2. For wired USB, use the ANTICATER configuration utility to assign the knob click to F13 and save it to the device.
  3. Launch VK01Studio.exe, select your audio devices and configure gestures, then save changes.

For the 2.4 GHz receiver, use the separate Treble + click mapping explained in the full English setup guide.
